# Dataset Source

## Dataset Overview

This project uses a lightweight M5-compatible sample dataset created specifically for Retail Demand Forecasting and Inventory Optimization.

The dataset is designed to follow the general structure of the original M5 Walmart dataset while keeping the data size small enough for development, testing, forecasting, and dashboard implementation.

## Dataset Details

- 20 products
- 2 stores
- Daily data from 2015 to 2016
- Sales information
- Calendar information
- Product price information

## Why a Lightweight Dataset?

The original M5 dataset is very large and requires significant storage and computational resources. Therefore, a lightweight M5-compatible sample is used for this project.

This smaller dataset allows the complete project pipeline to be developed and tested efficiently, including data cleaning, exploratory analysis, SQL transformations, dbt models, demand forecasting, inventory optimization, and dashboard development.

## Dataset Purpose

The dataset is used to demonstrate an end-to-end retail analytics workflow, from raw sales data preparation to demand forecasting and inventory-related insights.
